[의사소통](https://github.com/Songysp/DoctorChat_frontend)

 <details>
   <summary>펼치기/접기</summary>
 
* GPT-NeoX 기반의 Polygloy-ko 모델을 사용, 파인튜닝을 진행한 자연어처리 ai챗봇 모델

* Android, React, Python ..

GPT-NeoX 기반의 Polygloy-ko 모델을 활용하여, 사용자의 증상을 분석하고 의심되는 질병을 추정하며, 적합한 병원을 추천하고 간단한 대처 방법을 제공합니다.
